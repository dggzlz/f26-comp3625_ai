# You probably noticed you get slightly different results each time you run these scripts. Why is that?
## The line in both files ```train_idx = np.random.random(size=df.shape[0]) < 0.50``` is causing the values to change everytime. This is because everytime you run the program, the line always creates a random series of size 0 to len(df[0]) - 1, with a probability of 50% being True or False. You could fix this by running ```np.random.seed(42)```. This would fix the randomness to a specific value. 42 is standard number used to fixate randomness.

## The results for the optimal subset of features are somewhat similar, the big difference is when using all 13 features. When using Logistic regression, all features set performs really well, and often the drop of accuracy when using logistic regression is minimal. But when using KNN model the all features set performance drops drastically, and the optimal subset performance compare to this increases with big difference. This is because when Logistic Regression trains the model, Logistic Regression can assign the weigths to those noisy features to zero, and when doing the calculations, the model won't take into account those features since they contribute 0 to the sum. for KNN is different because those features act as noise and KNN is sensitive to noise, assigning a point that's closer to the noise to be similar to that noise, eventually generalizing other dataset to be similar to those when it was trained
